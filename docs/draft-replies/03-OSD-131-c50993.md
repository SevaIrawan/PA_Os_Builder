## Terjemahan
Menanggapi c50993. Dari sisi S-05 saya mengambil dua tugas, sesuai pembagian tugas Kent di OSD-116 c50257: (1) membangun kerangka project arsip dan dua Issue Type; (2) mengajukan field 纪律处分记录 ke Kent lewat pengajuan 三格, mengikuti 04.10 bagian 五.

Sebelum mulai, ada dua hal yang perlu diputuskan:
1. **Key project dan urutan pendaftaran di 04.1** (untuk Kayden).
   - Baris 04.1 masih 「候选｜待N5」, key dan Owner masih kosong.
   - 04.1 §1.1: kalau disetujui dibuat baru, tulis 「已裁决｜待创建｜{key yang dipesan}」; status 「运行中」 baru ditulis setelah project dibuat dan dibaca ulang.
   - 04.1 §二: kalau baris yang sudah diputuskan tidak ditemukan, pembangunan dihentikan dan dikembalikan untuk dilengkapi.
   - Jadi saya menunggu baris itu ditulis dulu, lalu membangun dan melapor di kartu ini.
   - Mohon diputuskan sekalian cara mendaftarkan satu project yang memuat dua jenis catatan.
   - Soal 04.8 §四 「先登记后上线」, pertanyaannya sama dengan Zefansstr di BO-3 butir 1; saya mengikuti jawaban Alden.
2. **Apakah Issue Type perlu didaftarkan di 04.10** (untuk Kent).
   - 04.10 §一 mengatur Issue Type bersama, dan §三 punya baris Issue Type.
   - Tapi pohon keputusan §2.1-A tidak menyebut Issue Type. Apakah dua Issue Type arsip ini perlu didaftarkan?

Tambahan: baris 04.1 untuk entitas yang sama masih menulis 「hanya bisa dilihat HR dan atasan terkait」. Di bagian 二 c50993, permintaan mengubah tulisan visibility hanya menyebut baris 04.8.
